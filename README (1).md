## 👨‍💻 About me

I'm **Rajan Prasaila Yadav**, a developer from **Nepal 🇳🇵**, pursuing **B.Tech in Computer Science & Engineering (Artificial Intelligence & Machine Learning)** at **SVCET, Chittoor, India**.

I enjoy building software end to end — understanding a real problem, designing the user experience, implementing APIs and data models, securing the system, and shipping a product people can use. My work spans **SaaS platforms, education technology, native Android applications, automation, and AI-powered experiences**.

- 🔭 **Building:** scalable education platforms, management systems, intelligent workflows, and mobile tools.
- 🧩 **Strengths:** full-stack product development, API and database design, RBAC, multi-tenant architecture, and UI/UX thinking.
- 🌱 **Exploring:** applied AI/ML, RAG, multilingual voice interfaces, AI agents, and system performance.
- 🤝 **Collaborating on:** meaningful open-source projects, ambitious startups, and real-world software challenges.
- 💬 **Ask me about:** Next.js, React, TypeScript, Go, PostgreSQL, product architecture, and Android development.
- ⚡ **My approach:** *Make it useful. Make it secure. Make it understandable. Then make it better.*

## 🧭 How I approach engineering

```text
01  Understand the problem  →  users, constraints, outcomes
02  Design the experience   →  flows, states, responsive UI
03  Model the system        →  data, boundaries, permissions
04  Build and integrate     →  frontend, APIs, background jobs
05  Validate and secure     →  tests, authorization, edge cases
06  Deploy and improve      →  feedback, observability, performance
```
